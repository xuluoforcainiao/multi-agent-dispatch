# multi-agent-dispatch

Coordinate tasks between multiple AI agents (wukong and qoderwork) using a shared DingTalk AI spread

## 安装

使用 GitHub CLI 安装：

```bash
gh skill install xuluoforcainiao/multi-agent-dispatch multi-agent-dispatch
```

## 使用

安装后，在 QoderWork 中提及或使用此 skill 时会自动激活。

你也可以通过以下方式手动触发：

```
请使用 multi-agent-dispatch skill 来帮我...
```
